# Weather App for Brookhaven, MS 🌤️

A simple weather display page showing current conditions for Brookhaven, Mississippi (Area Code: 39601).

## Features

- Beautiful gradient design with modern UI
- Displays current temperature, humidity, wind speed, and weather conditions
- Works directly from your browser
- Includes links to Weather.com and AccuWeather for detailed forecasts

## How to Use

Simply open this page in any web browser. The weather data will load automatically when you visit the site.

## External Weather Resources

For more detailed forecasts and historical data, you can also visit:

- [Weather.com - Brookhaven, MS](https://weather.com/weather/today/l/Brookhaven+MS)
- [AccuWeather - Brookhaven, MS](https://www.accuweather.com/en/us/brookhaven-ms/39601/current-weather/m7248_5)

## Notes

This is a static HTML page that displays weather information. The live weather API may be blocked by browser security when viewing from GitHub Pages due to CORS restrictions, but the page will still display with helpful links to external weather services.
